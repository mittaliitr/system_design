LeetCode 1570 - Dot Product of Two Sparse Vectors

🧩 Problem Explanation

You are given two sparse vectors (vectors that have many zero elements). Your task is to compute their dot product.

Example:
nums1 = [1, 0, 0, 2, 3]
nums2 = [0, 3, 0, 4, 0]

The dot product is:
1*0 + 0*3 + 0*0 + 2*4 + 3*0 = 8

💡 Approach 1: Using HashMap (Efficient for Sparse Vectors)

Store only the non-zero elements of the vector in a map — key as index and value as number. Then multiply values where both vectors have the same index. 


// Java code using HashMap

class SparseVector {
    Map map;

    SparseVector(int[] nums) {
        map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                map.put(i, nums[i]);
            }
        }
    }

    public int dotProduct(SparseVector vec) {
        int result = 0;
        for (int index : map.keySet()) {
            if (vec.map.containsKey(index)) {
                result += map.get(index) * vec.map.get(index);
            }
        }
        return result;
    }
}

// Example usage:
SparseVector v1 = new SparseVector(new int[]{1, 0, 0, 2, 3});
SparseVector v2 = new SparseVector(new int[]{0, 3, 0, 4, 0});
System.out.println(v1.dotProduct(v2)); // Output: 8

💡 Approach 2: Using Two Pointers (For Sorted Non-zero Indexes)

Store non-zero values as (index, value) pairs in two lists. Then move pointers to match indices and calculate the dot product. 


// Java code using Two Pointers

class SparseVector {
    List list;

    SparseVector(int[] nums) {
        list = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                list.add(new int[]{i, nums[i]});
            }
        }
    }

    public int dotProduct(SparseVector vec) {
        int i = 0, j = 0, result = 0;
        while (i < list.size() && j < vec.list.size()) {
            int idx1 = list.get(i)[0], idx2 = vec.list.get(j)[0];
            if (idx1 == idx2) {
                result += list.get(i)[1] * vec.list.get(j)[1];
                i++; j++;
            } else if (idx1 < idx2) {
                i++;
            } else {
                j++;
            }
        }
        return result;
    }
}

💡 Approach 3: Using Binary Search (When One Vector is Much Larger)

If one vector has far fewer non-zero entries, we can binary search those indices in the larger vector to find matches quickly. 


// Java code using Binary Search

class SparseVector {
    List list; // store [index, value]

    SparseVector(int[] nums) {
        list = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                list.add(new int[]{i, nums[i]});
            }
        }
    }

    public int dotProduct(SparseVector vec) {
        List smaller = this.list.size() < vec.list.size() ? this.list : vec.list;
        List larger = this.list.size() >= vec.list.size() ? this.list : vec.list;

        int result = 0;
        for (int[] pair : smaller) {
            int index = pair[0];
            int value = pair[1];
            int pos = binarySearch(larger, index);
            if (pos != -1) {
                result += value * larger.get(pos)[1];
            }
        }
        return result;
    }

    private int binarySearch(List list, int target) {
        int left = 0, right = list.size() - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (list.get(mid)[0] == target) return mid;
            else if (list.get(mid)[0] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
}

✅ Summary

  • Use HashMap when both vectors are sparse but not sorted.
  • Use Two Pointers when both vectors are sorted by index.
  • Use Binary Search when one vector is much smaller.
