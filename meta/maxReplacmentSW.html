3346. Maximum Frequency of an Element After Performing Operations I

Problem Summary

Given an array of numbers and a number k representing how many increments you can do, you want to find the maximum frequency of any element after performing at most k operations.

Operation allowed: increase any element by 1 per operation.

Goal

Find the maximum count of equal elements possible by increasing elements at most k times.

Example

Input: nums = [1, 2, 4], k = 5
Explanation: Increase 1 to 4 (3 increments), increase 2 to 4 (2 increments), total 5 increments.
Resulting array: [4, 4, 4]
Maximum frequency = 3

Approach

  1. Sort the array to work in ascending order.
  2. Use a sliding window with two pointers (left and right).
  3. Calculate total increments needed to make all elements in the window equal to nums[right].
  4. If increments needed > k, shrink the window from the left.
  5. Keep track of the maximum window size where increments needed ≤ k.

Why it works

By sorting, you ensure increments only move values up to the right (higher) element. The sliding window tries to find the largest group where all elements can be made equal within k increments.

Increments needed for a window of size n with largest element nums[right] is:
nums[right] * n - sum_of_elements_in_window

Java Code Example

import java.util.Arrays;

public class MaxFrequency {
    public int maxFrequency(int[] nums, int k) {
        Arrays.sort(nums);
        long total = 0;  // sum of elements in current window
        int left = 0;
        int maxFreq = 1;

        for (int right = 0; right < nums.length; right++) {
            total += nums[right];

            // While increments needed exceed k, shrink window
            while ((long)nums[right] * (right - left + 1) - total > k) {
                total -= nums[left];
                left++;
            }

            maxFreq = Math.max(maxFreq, right - left + 1);
        }

        return maxFreq;
    }

    public static void main(String[] args) {
        MaxFrequency mf = new MaxFrequency();
        int[] nums = {1, 2, 4};
        int k = 5;
        System.out.println(mf.maxFrequency(nums, k));  // Output: 3
    }
}
