🏊 Swim in Rising Water (LeetCode 778)

🧩 Problem Explanation

You are given an n × n grid where each cell represents an elevation (height). Water rises over time, and you can only move to a cell if the current water level is at least equal to that cell’s height.

Your goal: start at (0, 0) and reach (n − 1, n − 1) in the minimum possible time.

Example:

Input: grid = [
  [0,2],
  [1,3]
]
Output: 3

Explanation:
At time = 0, you're at (0,0)
At time = 1, water=1 → move to (1,0)
At time = 2, water=2 → still can’t reach (1,1)
At time = 3, water=3 → now you can reach (1,1)

💡 Approach 1: Binary Search + DFS (True/False Pattern)

We can use binary search over the possible time (water level) to find the smallest time T such that a path exists from start to end.

🎯 Logic:

  • Binary search between min = grid[0][0] and max = n² - 1.
  • For each mid, check if you can reach the end using DFS where every cell ≤ mid.
  • If path exists → true → try smaller mid.
  • If path doesn’t exist → false → try larger mid.

🧠 Java Code:

    private int n;
    private int[][] grid;
    private boolean[][] visited;
    private int[][] dirs = {{1,0}, {-1,0}, {0,1}, {0,-1}};

    public int swimInWater(int[][] grid) {
        this.grid = grid;
        n = grid.length;
        int left = grid[0][0], right = n * n - 1, ans = right;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            visited = new boolean[n][n];

            if (canReach(mid, 0, 0)) {
                ans = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return ans;

⚙️ Approach 2: Dijkstra / Min-Heap (Priority Queue)

We can treat each cell as a node, and move in the direction of the smallest elevation first. The answer is the maximum height encountered on the shortest path.
