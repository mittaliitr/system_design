Longest Repeating Character Replacement - Simple Explanation

Problem Statement

You are given a string s consisting of uppercase letters, and an integer k.

You can replace at most k characters in the string to make all characters in some substring the same.

Your task is to find the length of the longest substring that can be obtained by performing at most k replacements.

What does this mean?

Imagine you want a substring where all letters are identical, but you are allowed to change (replace) up to k letters to achieve that.

For example:

String: "AABABBA"

k: 1 (You can replace 1 character)

One longest substring you can get is "ABABBA" (from index 1 to 6).
By replacing just one 'A' with 'B', you make the whole substring all 'B's.
So the answer is 6.

How to solve it? (Sliding Window Intuition)

  • Use two pointers to represent a window (a substring).
  • Expand the window by moving the right pointer.
  • Keep track of the count of the most frequent character in the current window.
  • If the number of characters to replace (window size minus max frequency) exceeds k, move the left pointer to shrink the window.
  • Track the maximum valid window size during this process.

Why does this work?

The most frequent character count tells us how many letters don't need to be changed.

The difference between the window size and this count is how many characters we need to replace.

If that number is more than k, the window is invalid and needs to be shrunk.

Step-by-step Example

Given s = "AABABBA" and k = 1:

  • Window: "A" — max frequency = 1, replacements needed = 0 (valid)
  • Window: "AA" — max frequency = 2, replacements needed = 0 (valid)
  • Window: "AAB" — max frequency = 2, replacements needed = 1 (valid)
  • Window: "AABA" — max frequency = 3, replacements needed = 1 (valid)
  • Window: "AABAB" — max frequency = 3, replacements needed = 2 (> k, invalid)
  • Shrink window by moving left pointer...

Continue this process and find the longest valid window size, which is 4, 5, or 6 depending on replacements.

Java Code Implementation

class Solution {
    public int characterReplacement(String s, int k) {
        int left = 0;
        int maxCount = 0;  // max frequency of a char in current window
        int[] count = new int[26];
        int maxLength = 0;

        for (int right = 0; right < s.length(); right++) {
            count[s.charAt(right) - 'A']++;
            maxCount = Math.max(maxCount, count[s.charAt(right) - 'A']);

            // If replacements needed exceed k, shrink window
            while ((right - left + 1) - maxCount > k) {
                count[s.charAt(left) - 'A']--;
                left++;
            }

            maxLength = Math.max(maxLength, right - left + 1);
        }

        return maxLength;
    }
}

Summary

  • Use a sliding window to scan through the string.
  • Keep track of the count of characters in the window.
  • Maintain the count of the most frequent character.
  • Adjust the window size to keep replacements ≤ k.
  • The longest window size found is the answer.
