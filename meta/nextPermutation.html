Quick algorithm (3 steps)
  1. Find the pivot: the first index i from the right where nums[i] < nums[i+1].
  2. Find the successor: smallest element to the right of i that is > nums[i] (index j).
  3. Swap nums[i] and nums[j], then reverse the suffix after i (to get the smallest arrangement).

If no pivot found, the array is the highest permutation → reverse whole array to get lowest.

Java solution (reference) 
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        reverse(nums, i + 1, n - 1);
    }

    private void swap(int[] nums, int i, int j) {
        int t = nums[i]; nums[i] = nums[j]; nums[j] = t;
    }

    private void reverse(int[] nums, int l, int r) {
        while (l < r) { swap(nums, l++, r--); }
    }
}

Notes / Tips
  • Finding the pivot from the right ensures we change the smallest possible suffix to get the immediate next permutation.
  • Reversing the suffix after swapping guarantees the suffix becomes the smallest possible order (ascending).
  • Time: O(n). Space: O(1) extra space (in-place).
