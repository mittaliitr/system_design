LeetCode 239: Sliding Window Maximum

Problem Summary

Given an array of numbers and a window size k, slide the window from left to right across the array. For each window position, find the maximum number inside that window.

Example

Input: nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3

Windows and their maximums:

  • [1, 3, -1] → max is 3
  • [3, -1, -3] → max is 3
  • [-1, -3, 5] → max is 5
  • [-3, 5, 3] → max is 5
  • [5, 3, 6] → max is 6
  • [3, 6, 7] → max is 7

Output: [3, 3, 5, 5, 6, 7]

Efficient Approach: Using a Deque

Instead of scanning each window fully (which can be slow), we use a deque to store indexes of elements. The deque keeps indexes of elements in decreasing order of their values. The front of the deque always holds the index of the maximum element.

Steps:

  1. Remove indexes that are out of the current window.
  2. Remove elements smaller than the current element from the back (they can never be max if a bigger element comes later).
  3. Add the current element index at the back.
  4. The element at the front of the deque is the max of the current window.

Java Code

import java.util.Deque;
import java.util.LinkedList;

public class SlidingWindowMaximum {
    public static int[] maxSlidingWindow(int[] nums, int k) {
        Deque<Integer> deque = new LinkedList<>();
        int[] result = new int[nums.length - k + 1];
        int ri = 0;

        for (int i = 0; i < nums.length; i++) {
            // Remove indexes out of window
            if (!deque.isEmpty() && deque.peek() < i - k + 1) {
                deque.poll();
            }

            // Remove smaller values from the back
            while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
                deque.pollLast();
            }

            // Add current element at the back
            deque.offer(i);

            // Add to result after the first window is complete
            if (i >= k - 1) {
                result[ri++] = nums[deque.peek()];
            }
        }
        return result;
    }

    public static void main(String[] args) {
        int[] nums = {1, 3, -1, -3, 5, 3, 6, 7};
        int k = 3;
        int[] result = maxSlidingWindow(nums, k);

        System.out.print("Sliding window maximums: [");
        for (int i = 0; i < result.length; i++) {
            System.out.print(result[i]);
            if (i < result.length - 1) System.out.print(", ");
        }
        System.out.println("]");
    }
}

Walkthrough of the Code

Variables:

  • deque: holds indexes of elements, ordered so the largest element's index is at the front.
  • result: stores max values for each window.
  • ri: index for result array.

Loop: For each element in nums:

  1. Remove indexes from the front of the deque if they are outside the current window (i - k + 1).
  2. Remove smaller elements from the back to maintain decreasing order.
  3. Add current index at the back.
  4. If window size reached, add max (front of deque) to result.
