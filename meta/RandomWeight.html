LeetCode 528: Random Pick With Weight

🧮 What the problem asks

You’re given an array w of positive integers, where each value w[i] is a “weight” for index i. You must implement a class so that:

  • Calling pickIndex() returns an index i in the range [0, w.length-1].
  • The probability of returning index i is proportional to its weight:
    Pr(return i) = w[i] / sum(w)

Example: if w = [1, 3], then index 0 should be returned 25% of the time, and index 1 should be returned 75% of the time. AlgoMonster

🔍 Why this is interesting

If all weights are equal, picking an index uniformly is easy. But here, weights differ, so higher weights should be picked more often.

A naive solution (repeating indices according to weights) is inefficient for large numbers. We need a more efficient approach.

✅ How to solve it — in simple steps

  1. Compute a prefix sum array of the weights. 
    w = [2, 5, 3]
prefix = [2, 7, 10]
  2. Generate a random target number between 1 and total weight.
  3. Find the index corresponding to the target using the prefix sum array (binary search is efficient here).

📝 Example walkthrough

Given w = [1,3,2]:

  • Total weight = 6
  • Prefix sums: [1, 4, 6]
  • Random integer x in [1…6]
  • Index mapping:
    • x=1 → index 0 (1/6 probability)
    • x=2,3,4 → index 1 (3/6 probability)
    • x=5,6 → index 2 (2/6 probability)

Matches the desired probabilities. SparkCodehub

🚧 Things to watch out for

  • Random range should match the total weight correctly.
  • Prefix sum construction is O(n), pickIndex() is O(log n) using binary search.
  • Edge cases: single element → 100% probability.
  • Beware of integer overflow for large weights.

💻 Java Implementation

import java.util.Random;

class Solution {

    Random random;
    int[] wSums;

    public Solution(int[] w) {
        this.random = new Random();
        for(int i=1; i<w.length; ++i)
            w[i] += w[i-1];
        this.wSums = w;
    }

    public int pickIndex() {
        int len = wSums.length;
        int idx = random.nextInt(wSums[len-1]) + 1;
        int left = 0, right = len - 1;

        while(left <= right){
            int mid = left + (right-left)/2;
            if(wSums[mid] == idx)
                return mid;
            else if(wSums[mid] < idx)
                left = mid + 1;
            else
                right = mid-1;
        }
        return left;
    }
}
