Search in Rotated Sorted Array — T / F Visualization

This page explains the rotated-array binary search and visualizes each iteration as a T / F classification of the halves (where T = target could be here, F = cannot be here). The example used: [4,5,6,7,0,1,2], target = 0.

Problem (short)

Given a sorted array rotated at unknown pivot, find the index of target in O(log n), or -1 if not found. Elements are distinct.

Key invariant

At any step [left..right], one half (left..mid or mid..right) is strictly sorted. Decide which half is sorted, check whether target lies inside that half → that half is logically True (possible), the other half False (impossible). Continue binary search inside True half.

Java implementation (while left ≤ right)

// typical inclusive binary-search on indices
class Solution {
  public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
      int mid = left + (right - left) / 2;
      if (nums[mid] == target) return mid;

      // left half sorted?
      if (nums[left] <= nums[mid]) {
        if (nums[left] <= target && target < nums[mid]) {
          right = mid - 1;    // target in left sorted half
        } else {
          left = mid + 1;     // otherwise go right
        }
      } else {
        // right half sorted
        if (nums[mid] < target && target <= nums[right]) {
          left = mid + 1;     // target in right sorted half
        } else {
          right = mid - 1;    // otherwise go left
        }
      }
    }
    return -1;
  }
}
