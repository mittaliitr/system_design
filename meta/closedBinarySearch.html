LeetCode 270 — Closest Binary Search Tree Value

Problem • Binary Search Tree • Simulation
Single-file HTML: statement, explanation, Java & JS solutions, interactive demo

Problem statement

Given the root of a binary search tree and a target value, return the value in the BST that is closest to the target.

Notes: The tree is a valid BST — left children < node < right children. You may assume there is at least one node.

Example

Input: root = [4,2,5,1,3], target = 3.714286
Output: 4
Explanation: 4 is closer to the target than 3.

Idea & approaches

  1. Iterative BST-guided search (best) — Use BST property. At each node, compare node.val with target; update the closest seen so far. Then move left or right depending on whether target < node.val or > node.val. This visits along a root-to-leaf path, so time O(h) where h is tree height (O(log n) average, O(n) worst).
  2. Recursive version — same logic but written recursively.
  3. In-order traversal — produce a sorted list of values and perform binary search on it; O(n) time and O(n) extra space. Useful if you want multiple queries on the same tree.

Why the iterative approach is optimal

Because a BST orders values, you can discard one subtree at every comparison: if target < node.val, the best candidate must be in the left subtree or the current node (so search left), otherwise search right. That gives O(h) time and O(1) extra space.

Java — iterative (recommended)

// Java iterative solution: O(h) time, O(1) space
public class Solution {
    public int closestValue(TreeNode root, double target) {
        int closest = root.val;
        TreeNode node = root;
        while (node != null) {
            // update closest if current node is closer to target
            if (Math.abs(node.val - target) < Math.abs(closest - target)) {
                closest = node.val;
            }
            // decide direction using BST property
            if (target < node.val) node = node.left;
            else node = node.right;
        }
        return closest;
    }
}

// Definition for a binary tree node (LeetCode style):
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }
}

Java — recursive

public class Solution {
    public int closestValue(TreeNode root, double target) {
        return closestHelper(root, target, root.val);
    }

    private int closestHelper(TreeNode node, double target, int closest) {
        if (node == null) return closest;
        if (Math.abs(node.val - target) < Math.abs(closest - target)) {
            closest = node.val;
        }
        if (target < node.val) return closestHelper(node.left, target, closest);
        else return closestHelper(node.right, target, closest);
    }
}

Complexity

  • Time: O(h) — h is tree height (balanced: O(log n), worst-case skewed: O(n))
  • Space: O(1) iterative, O(h) recursion stack for recursive approach

Dry run (iterative) — root=[4,2,5,1,3], target=3.714...

  1. Start: closest = 4 (root). node = 4. |4 - 3.714| = 0.286
  2. target > 4? No — target < 4, go left to node 2. Check |2 - target| = 1.714 > 0.286 → closest stays 4.
  3. target > 2? Yes — go right to node 3. |3 - target| = 0.714 > 0.286 → closest stays 4.
  4. node 3 has no right child — done. Return 4.
