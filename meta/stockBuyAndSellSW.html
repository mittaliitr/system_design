Best Time to Buy and Sell Stock - Sliding Window Variations

This page summarizes multiple LeetCode stock trading problems that can be solved using Sliding Window / Two Pointer techniques or their conceptual extensions.

1. Best Time to Buy and Sell Stock (One Transaction)

LeetCode #121 - You can only make one buy and one sell.

Approach: Use two pointers - left as buy day, right as sell day. Move right forward, update minimum price (buy day), track max profit.

// Java code
class Solution {
    public int maxProfit(int[] prices) {
        int left = 0, right = 1, maxProfit = 0;
        while (right < prices.length) {
            if (prices[right] > prices[left]) {
                maxProfit = Math.max(maxProfit, prices[right] - prices[left]);
            } else {
                left = right;
            }
            right++;
        }
        return maxProfit;
    }
}

2. Best Time to Buy and Sell Stock II (Multiple Transactions)

LeetCode #122 - You can complete unlimited transactions (buy/sell multiple times).

Approach: Add all positive differences between consecutive days. Each rising edge counts as profit.

// Java code
class Solution {
    public int maxProfit(int[] prices) {
        int profit = 0;
        for (int i = 1; i < prices.length; i++) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
}

3. Best Time to Buy and Sell Stock III (At Most Two Transactions)

LeetCode #123 - You can complete at most two transactions.

Approach: Use two passes: - Forward pass to track max profit until day i. - Backward pass to track max profit from day i to end. Combine results for maximum total profit. This extends sliding window to two overlapping windows.

// Java code snippet (core idea)
public int maxProfit(int[] prices) {
    int n = prices.length;
    int[] leftProfit = new int[n];
    int[] rightProfit = new int[n + 1];

    // Forward pass
    int minPrice = Integer.MAX_VALUE;
    for (int i = 0; i < n; i++) {
        minPrice = Math.min(minPrice, prices[i]);
        leftProfit[i] = i == 0 ? 0 : Math.max(leftProfit[i - 1], prices[i] - minPrice);
    }

    // Backward pass
    int maxPrice = Integer.MIN_VALUE;
    for (int i = n - 1; i >= 0; i--) {
        maxPrice = Math.max(maxPrice, prices[i]);
        rightProfit[i] = Math.max(rightProfit[i + 1], maxPrice - prices[i]);
    }

    int maxTotal = 0;
    for (int i = 0; i < n; i++) {
        maxTotal = Math.max(maxTotal, leftProfit[i] + rightProfit[i + 1]);
    }

    return maxTotal;
}

4. Best Time to Buy and Sell Stock IV (At Most K Transactions)

LeetCode #188 - You can complete at most k transactions.

Approach: Generalizes the two-transaction case using dynamic programming over k transaction windows. Conceptually multiple sliding windows track profits for each transaction number.

Code is more complex and usually solved with DP arrays rather than simple sliding window, but idea extends the two-window approach.

5. Best Time to Buy and Sell Stock with Cooldown

LeetCode #309 - After selling, you must wait 1 day before buying again.

Approach: Sliding window here skips a day (cooldown). Use states to track buy/sell with cooldown constraints.

// Java code using DP states
public int maxProfit(int[] prices) {
    int n = prices.length;
    int[] sell = new int[n];
    int[] buy = new int[n];
    buy[0] = -prices[0];
    sell[0] = 0;

    for (int i = 1; i < n; i++) {
        buy[i] = Math.max(buy[i - 1], (i - 2 >= 0 ? sell[i - 2] : 0) - prices[i]);
        sell[i] = Math.max(sell[i - 1], buy[i - 1] + prices[i]);
    }
    return sell[n - 1];
}

6. Best Time to Buy and Sell Stock with Transaction Fee

LeetCode #714 - Each transaction pays a fixed fee.

Approach: Track holding state and cash state, subtract fee at selling time. Sliding window analogy applies with adjusted buy prices.

// Java code
class Solution {
    public int maxProfit(int[] prices, int fee) {
        int hold = -prices[0];
        int cash = 0;
        for (int i = 1; i < prices.length; i++) {
            cash = Math.max(cash, hold + prices[i] - fee);
            hold = Math.max(hold, cash - prices[i]);
        }
        return cash;
    }
}

7. Custom Variation: Restrict Transactions within a Window Size k

You can only buy and sell within any subarray/window of length k.

Approach: Use a fixed-size sliding window to find maximum profit inside each window.
