🧩 Binary Search Boundary Pattern

Example Question:

162. Find Peak Element

Solution. Find Peak Element

🔍 Intuition

We are asked to find a peak element — an index i where nums[i] > nums[i + 1]. This is a perfect example of a binary search on a boolean boundary.

We can transform the array into a boolean form based on the condition:
arr[i] > arr[i + 1] → True if peak or after it, False otherwise.

🖼️ Visual Explanation

The array transitions from increasing (False) to decreasing (True), marking the boundary at the peak.

⚙️ Binary Search Pattern


    import java.util.Arrays;
import java.util.List;
import java.util.Scanner;
import java.util.stream.Collectors;

class Solution {
    public static int peakOfMountainArray(List arr) {
        int alen = arr.size();
        int left = 0;
        int right = alen - 1;
        int boundaryIndex = -1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (arr.get(mid) > arr.get(mid + 1)) {
                boundaryIndex = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return boundaryIndex;
    }

    public static List splitWords(String s) {
        return s.isEmpty() ? List.of() : Arrays.asList(s.split(" "));
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        List arr = splitWords(scanner.nextLine()).stream().map(Integer::parseInt).collect(Collectors.toList());
        scanner.close();
        int res = peakOfMountainArray(arr);
        System.out.println(res);
    }
}

🧠 Pattern Key Idea

Convert the question into “Find the first True” or “Find the last False” problem.

Common Examples Using This Pattern:

  • Koko Eating Bananas → Find minimum speed satisfying condition
  • Capacity To Ship Packages Within D Days → Smallest capacity satisfying condition
  • Square Root → Find floor boundary
  • Search Insert Position → Find transition between smaller and larger values

🧩 Takeaway

  • Reduces to finding a boolean transition (False → True)
  • Binary search efficiently locates that boundary
  • Time Complexity: O(log n)
