Top K Frequent Elements — Solution (Java)

This page explains the min-heap-based solution for Top K Frequent Elements (LeetCode 347) and shows the exact Java implementation you provided, plus a small interactive demo (JavaScript) to try inputs in the browser.

Key idea

Use a min-heap (PriorityQueue in Java with a comparator) that stores at most k numbers keyed by their frequency. Whenever the heap size exceeds k, remove the element with the smallest frequency. At the end the heap contains the k most frequent elements.

O(N + N log k) when k < N. Special case: if k == N, return input — O(1) extra work.
Space complexity: O(N + k) for the frequency map + heap.

Java implementation

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        if (k == nums.length) {
            return nums;
        }
        HashMap countHashMap = new HashMap<>();
        for (int n : nums) {
            countHashMap.put(n, countHashMap.getOrDefault(n, 0) + 1);
        }

        Queue heap = new PriorityQueue<>((n1, n2) -> countHashMap.get(n1) - countHashMap.get(n2));
        for (int n : countHashMap.keySet()) {
            heap.add(n);
            if (heap.size() > k) {
                heap.poll();
            }
        }

        int[] top = new int[k];
        for (int i = k - 1; i >= 0; i--) {
            top[i] = heap.poll();
        }
        return top;
    }
}
