LeetCode 1004: Max Consecutive Ones III

Problem Statement

You are given:

  • An array nums consisting of only 0s and 1s.
  • An integer k.

You can flip at most k zeros to ones. Find the length of the longest contiguous subarray containing only 1s after flipping.

Example

Input:

nums = [1,1,0,0,1,1,1,0,1,1], k = 2

Output: 7

Explanation: Flip two zeros to ones to get the longest sequence of 1s of length 7.

Solution Approach

We can solve this using the sliding window technique:

  1. Keep a window [left, right] representing the current subarray.
  2. Count how many zeros are in the window.
  3. If the zero count exceeds k, shrink the window from the left until zeros ≤ k.
  4. Keep track of the maximum window length where zeros ≤ k.

Java Code


class Solution {
    public int longestOnes(int[] nums, int k) {
        int left = 0;
        int maxLen = 0;
        int zeroCount = 0;

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) {
                zeroCount++;
            }

            while (zeroCount > k) {
                if (nums[left] == 0) {
                    zeroCount--;
                }
                left++;
            }

            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}

Step-by-Step Sliding Window Example

Using nums = [1, 1, 0, 0, 1, 1, 1, 0, 1, 1], k = 2:

Step 1: Window: [1], zeroCount=0, maxLen=1
Step 2: Window: [1, 1], zeroCount=0, maxLen=2
Step 3: Window: [1, 1, 0], zeroCount=1, maxLen=3
Step 4: Window: [1, 1, 0, 0], zeroCount=2, maxLen=4
Step 5: Window: [1, 1, 0, 0, 1], zeroCount=2, maxLen=5
Step 6: Window: [1, 1, 0, 0, 1, 1], zeroCount=2, maxLen=6
Step 7: Window: [1, 1, 0, 0, 1, 1, 1], zeroCount=2, maxLen=7
Step 8: Window: [1,1,1,1,1], zeroCount=2 (after shrinking), maxLen=7
Step 9: Window: [0,1,1,1,0,1], zeroCount=2, maxLen=7
Step 10: Window: [0,1,1,1,0,1,1], zeroCount=2, maxLen=7

Final Answer

maxLen = 7
