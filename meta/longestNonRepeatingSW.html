3. Longest Substring Without Repeating Characters (Optimized)

🧠 Problem

Given a string s, find the length of the longest substring without repeating characters.

💡 Example

Input: "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3.

🚀 Optimized Idea

Use the sliding window technique with a HashMap to jump directly to the next position after a repeating character.

This avoids removing characters one by one, improving efficiency to O(n).

🧩 Algorithm Steps

  1. Use two pointers start and end to define the current window.
  2. Keep a HashMap that stores each character's last seen index.
  3. If a character repeats and is within the current window, move start to map.get(c) + 1.
  4. Update the max window size on each step.

💻 Java Code (Optimized O(n))

class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int maxLen = 0;
        int start = 0;

        for (int end = 0; end < s.length(); end++) {
            char c = s.charAt(end);

            // If character is seen before, move start pointer
            if (map.containsKey(c)) {
                start = Math.max(start, map.get(c) + 1);
            }

            // Update character's latest index
            map.put(c, end);

            // Update max length
            maxLen = Math.max(maxLen, end - start + 1);
        }

        return maxLen;
    }
}
