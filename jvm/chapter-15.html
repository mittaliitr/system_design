Project Valhalla: The Death of java.lang.Object

Revolutionizing Java’s object model by introducing value types to reduce memory overhead and improve performance.

What is Project Valhalla?

Project Valhalla is an OpenJDK project aimed at redesigning Java's memory and type system to support value types (also called inline types). It moves away from the traditional heavyweight reference-based java.lang.Object to enable efficient, immutable, and compact data representations.

  • Introduces inline classes that behave like primitives but support rich features.
  • Allows storing data inline, avoiding object header and reference overhead.
  • Improves cache locality and reduces garbage collection pressure.

Why "The Death of java.lang.Object"?

Currently, every Java object inherits from java.lang.Object, which adds header metadata and reference indirection. Valhalla proposes:

  • Value types that don't require object headers or references.
  • Inline storage of data, eliminating unnecessary heap allocations.
  • Breaking the one-size-fits-all Object model by enabling efficient data containers.

This reduces overhead and brings Java closer to performance levels seen in languages like C++ and Rust.

Benefits of Value Types

  • Performance: Reduced memory footprint and fewer GC cycles.
  • Efficiency: Better CPU cache utilization and less pointer chasing.
  • Safety: Value types remain immutable and safe by design.
  • Simplicity: Inline classes can be used just like regular classes.

Example: Inline Class Syntax

inline class Point {
    private final int x;
    private final int y;

    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    public int x() { return x; }
    public int y() { return y; }

    public Point move(int dx, int dy) {
        return new Point(x + dx, y + dy);
    }
}

This defines a compact, immutable Point type that can be stored inline without object header overhead.

Current Status & Future Outlook

  • Project Valhalla is actively under development in OpenJDK.
  • Preview and incubator features are available in recent JDK builds.
  • Expected to drastically change Java performance and memory models in the coming years.
