Chapter 1 – The Birth of Java and the JVM (1995–2025)

Thirty Years That Changed Computing Forever

In 1991, James Gosling and the Green Team set out to build software for smart appliances. They created Oak, renamed it Java, and on May 23, 1995, demonstrated the first Java applet running identically across Windows, Solaris, and Mac OS. “Write Once, Run Anywhere” was born.

The JVM — a tiny virtual machine interpreting portable bytecode — was the real revolution.

The JVM is now one of the most sophisticated pieces of software on the planet.
