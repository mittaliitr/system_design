The Vector API & SIMD on the JVM

Leveraging Single Instruction Multiple Data (SIMD) to accelerate numeric computations in Java.

What is SIMD?

SIMD stands for Single Instruction Multiple Data. It is a parallel computing technique where a single CPU instruction operates simultaneously on multiple data points. Modern CPUs support SIMD instructions to speed up data-parallel tasks like multimedia processing, scientific computing, and machine learning.

The Java Vector API

Introduced as an incubating API in recent JDK releases, the Java Vector API provides a platform-agnostic way to express vector computations that the JVM can compile down to efficient SIMD instructions at runtime.

  • Enables developers to write clean, portable vectorized code in Java.
  • Abstracts hardware-specific SIMD instructions, supporting multiple CPU architectures.
  • Supports operations on vectors of primitive types like int, float, and double.

Benefits of Using the Vector API

  • Performance: Significant speedups for numeric-heavy workloads by parallelizing operations.
  • Portability: Same Java code runs on different CPUs without modification.
  • Maintainability: Easier than using JNI or assembly for SIMD optimization.

Example Usage

import jdk.incubator.vector.IntVector;
import jdk.incubator.vector.VectorSpecies;

public class VectorExample {
    private static final VectorSpecies<Integer> SPECIES = IntVector.SPECIES_PREFERRED;

    public static void addVectors(int[] a, int[] b, int[] c) {
        int i = 0;
        int length = a.length;
        for (; i <= length - SPECIES.length(); i += SPECIES.length()) {
            var va = IntVector.fromArray(SPECIES, a, i);
            var vb = IntVector.fromArray(SPECIES, b, i);
            var vc = va.add(vb);
            vc.intoArray(c, i);
        }
        // Handle remaining elements
        for (; i < length; i++) {
            c[i] = a[i] + b[i];
        }
    }
}

This example shows adding two integer arrays using vector operations for the bulk of the work, falling back to scalar operations for leftovers.

Current Status and Future

  • The Vector API is incubating in JDK 16+ and evolving in subsequent releases.
  • Hardware support is expanding, with Intel, AMD, and ARM SIMD extensions targeted.
  • Ongoing work to extend support to more data types and operations.
