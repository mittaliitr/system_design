Chapter 1 – The Birth of Java and the JVM (1995–2025)

Thirty Years That Changed Computing Forever

1.1 The Secret Project Called “Oak”

In the spring of 1991, a small team of engineers at Sun Microsystems left the corporate campus in Mountain View, California, and set up a secret lab in a nondescript building at 100 Hamilton Avenue in Palo Alto. The team was led by James Gosling, Mike Sheridan, and Patrick Naughton. Officially, they were working on the “Green Project.” Unofficially, they wanted to build the future of consumer electronics.

Their bet was simple and radical: the next big computing platforms would not be PCs or workstations, but everyday appliances: set-top boxes, smart toasters, interactive televisions, and handheld devices. All of these devices would be made by different manufacturers, run different CPUs, and have wildly different operating systems.

The only sane way to write software for such a fragmented world, they concluded, was to invent a new language that compiled to an intermediate, hardware-independent format and a tiny virtual machine that could be ported everywhere.

The language was first called Oak (after the tree outside Gosling’s window). By 1995 it was renamed Java. The virtual machine was simply called the JVM.

1.2 May 23, 1995 – The Day the Web Discovered Java

On May 23, 1995, at SunWorld Expo in San Francisco, John Gage and James Gosling stood on stage and did something that looked like magic: they ran the same Java applet (a bouncing Duke animation) inside Netscape Navigator on Windows, Solaris, and Mac OS simultaneously.

The audience erupted. The phrase “Write Once, Run Anywhere™” was born that day, and it was not marketing hype; it was a technical fact.

1.3 The Three Original Promises of Java (1995)

  1. Platform Independence – The same .class file runs on any device with a JVM.
  2. Security – Bytecode verification, the Security Manager, and sandboxing made applets safe.
  3. Simplicity – C++ without pointers, manual memory management, or header files.
