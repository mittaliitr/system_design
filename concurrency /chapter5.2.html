Chapter 5 – Blocking Queues & Producer-Consumer

BlockingQueue — The Perfect Buffer

java.util.concurrent.BlockingQueue is a thread-safe queue that blocks when:

  • You put() into a full queue
  • You take() from an empty queue
No more wait()/notify() boilerplate.
No more race conditions.
Just put() and take().

One-Liner Producer-Consumer

BlockingQueue queue = new ArrayBlockingQueue<>(100);

// Producer
executor.submit(() -> {
    while (running) {
        Task task = produce();
        queue.put(task);  // Blocks when full
    }
});

// Consumer
executor.submit(() -> {
    while (running) {
        Task task = queue.take();  // Blocks when empty
        process(task);
    }
});
No synchronization
No wait()/notify()
No race conditions
No busy waiting

Key Takeaways

1. BlockingQueue = thread-safe queue with blocking operations

2. put() blocks when full → natural backpressure

3. take() blocks when empty → no busy waiting

4. Four method families: blocking, timeout, non-blocking, exception-throwing

5. 7 major implementations — choose by use case

6. The perfect producer-consumer solution
