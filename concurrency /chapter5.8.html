SQS = Serverless BlockingQueue

// Producer
sqs.sendMessage(new SendMessageRequest(queueUrl, "order-123"));

// Consumer
while (true) {
    ReceiveMessageResult msg = sqs.receiveMessage(queueUrl);
    for (Message m : msg.getMessages()) {
        process(m.getBody());
        sqs.deleteMessage(queueUrl, m.getReceiptHandle());
    }
}
SQS features:
• Unlimited throughput
• At-least-once / exactly-once
• FIFO queues with ordering
• Dead-letter queues
