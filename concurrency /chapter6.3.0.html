6.3 Structured Concurrency

StructuredTaskScope — No More Orphaned Threads

Automatic cancellation, error propagation, and clean shutdown

Chapter 6 – Project Loom

The Orphaned Thread Nightmare

With virtual threads, creating millions is easy.
But what happens when the parent task fails or is cancelled?

Old Way — Orphaned Threads Danger 
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    executor.submit(() -> longRunningTask());   // Child
    throw new RuntimeException("Parent failed!");
}
// Child keeps running forever → leak!
StructuredTaskScope — Automatic Cancellation Safe 
try (var scope = new StructuredTaskScope()) {
    scope.fork(() -> longRunningTask());
    throw new RuntimeException("Parent failed!");
} // Scope closes → all child tasks cancelled!
Structured concurrency:
Child tasks are scoped to the lifetime of the parent.
Parent ends → children cancelled automatically.

StructuredTaskScope — The New Primitive

// Java 21+ (incubating → preview → stable in 22+)
try (var scope = new StructuredTaskScope()) {

    Future user  = scope.fork(() -> fetchUser());
    Future order = scope.fork(() -> fetchOrder());

    scope.join();           // Wait for both (or first failure)
    scope.throwIfFailed();  // Propagate exception

    System.out.println(user.resultNow() + order.resultNow());

} // Auto-shutdown + cancel unfinished
Magic:
• fork() → virtual thread per subtask
• join() → wait for completion
• Scope close → unfinished tasks cancelled
• Exceptions propagated

Built-in Policies

// Shutdown on first success (racing)
try (var scope = new StructuredTaskScope.ShutdownOnSuccess()) {
    scope.fork(() -> callServiceA());
    scope.fork(() -> callServiceB());
    scope.join();
    String result = scope.result();  // First successful
}

// Shutdown on first failure
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    scope.fork(task1);
    scope.fork(task2);
    scope.join();
    scope.throwIfFailed(e -> new WebApplicationException(e));
}

Real-World Patterns

Resilient Service Call
try (var scope = new StructuredTaskScope.ShutdownOnSuccess()) {
    scope.fork(() -> userServiceA.get(id));
    scope.fork(() -> userServiceB.get(id));
    scope.join();
    return scope.result();  // First successful
}
Parallel Data Fetch
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    var userF  = scope.fork(() -> fetchUser());
    var orderF = scope.fork(() -> fetchOrders());
    var prefF  = scope.fork(() -> fetchPrefs());

    scope.join();
    scope.throwIfFailed();

    return new Dashboard(userF.resultNow(), orderF.resultNow(), prefF.resultNow());
}

Key Takeaways

1. StructuredTaskScope = structured concurrency for virtual threads

2. fork() + join() in try-with-resources

3. Automatic cancellation on scope close

4. Built-in policies: ShutdownOnSuccess, ShutdownOnFailure

5. No more orphaned tasks or memory leaks
