Multithreading: The Core Idea

Multithreading is the ability of a CPU (or CPUs) to execute multiple threads of instructions concurrently within a single process.

First Java Thread: Hello World

// Extend Thread
class MyThread extends Thread {
    public void run() {
        System.out.println("Hello from thread!");
    }
}

// Or implement Runnable (preferred)
class MyTask implements Runnable {
    public void run() {
        System.out.println("Task running...");
    }
}

public class Main {
    public static void main(String[] args) {
        Thread t1 = new MyThread();
        Thread t2 = new Thread(new MyTask());

        t1.start();  // Don't call run() directly!
        t2.start();
    }
}
Never call run() directly — use start() to spawn OS thread

Key Takeaways

1. Multithreading = multiple threads in one process.

2. Threads share memory → fast, but need synchronization.

3. Enables responsiveness, throughput, scalability.

4. Java: Thread class or Runnable interface.

5. Use start(), not run().

6. Concurrency ≠ Parallelism.
