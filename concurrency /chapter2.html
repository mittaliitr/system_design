What Are Registers?

Registers are the fastest memory in a computer — built directly into the CPU chip. They hold data the CPU is actively working on during the Fetch-Decode-Execute cycle.

Speed: ~0.5 nanoseconds access time
Size: Only 16–64 per core
Cost: Most expensive per byte

MOV RAX, 42        ; Load 42 into RAX register

Registers in Java Multithreading

When you write Java code like: 

int sum = a + b;  // a, b loaded into CPU registers!

The JVM compiles this to assembly that uses registers. In multithreading:

  • Each thread gets its own register set (per core)
  • Shared variables live in RAM/cache → need synchronization
  • volatile forces register → memory flush
Critical Insight: Thread-local variables often stay in registers → no synchronization needed!

Key Takeaways

1. Registers = fastest memory, inside CPU.

2. Only dozens per core, used in every FDE cycle.

3. General-purpose (RAX, RBX), special (RIP, RSP).

4. In Java: local vars → registers, shared → RAM.

5. volatile = "don’t keep in register only"
