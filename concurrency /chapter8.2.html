Architecture: Virtual Threads Power Everything

sequenceDiagram participant Client participant Server participant VT as Virtual Thread participant Room participant Broadcast Client->>Server: Connect Server->>VT: Thread.ofVirtual().start() VT->>Room: join("global") loop Every message Client->>VT: send message VT->>Broadcast: to all in room Broadcast-->>Client: deliver end Client->>Server: Disconnect VT->>Room: leave
Key:
• One virtual thread per client
• Blocking I/O → no wasted carrier threads
• ScopedValue for user context
• StructuredTaskScope for room broadcast

Core Server with Virtual Threads (Java 21+)

public class ChatServer {
    private static final ScopedValue CURRENT_USER = ScopedValue.newInstance();

    public static void main(String[] args) throws IOException {
        ServerSocket server = new ServerSocket(8080);

        try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
            while (true) {
                Socket client = server.accept();
                executor.submit(() -> handleClient(client));
            }
        }
    }

    private static void handleClient(Socket client) {
        try (client; var in = new BufferedReader(new InputStreamReader(client.getInputStream()));
             var out = new PrintWriter(client.getOutputStream(), true)) {

            out.println("Welcome! Enter your name:");
            String name = in.readLine();
            User user = new User(name, client);

            ScopedValue.where(CURRENT_USER, user)
                .run(() -> {
                    Room.join("global", user);
                    out.println("Joined global chat!");

                    String line;
                    while ((line = in.readLine()) != null) {
                        if (line.startsWith("/pm ")) {
                            // private message
                        } else {
                            Room.broadcast("global", user.name() + ": " + line);
                        }
                    }
                });

        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            Room.leave("global", CURRENT_USER.get());
        }
    }
}

Room Broadcast with StructuredTaskScope

static void broadcast(String room, String message) {
    List users = Room.getUsers(room);

    try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
        for (User user : users) {
            scope.fork(() -> {
                user.send(message);
                return null;
            });
        }
        scope.join();
        scope.throwIfFailed();
    } catch (Exception e) {
        // log error
    }
}
