Chapter 0 – Computer Architecture & Concurrency Foundations

Think of a Parking Lot

5 parking spots (shared resource). Cars (threads) arrive and leave. How to manage access?

Analogy: A semaphore is a ticket counter. It tracks available spots and makes cars wait when full.

Semaphore: A Counter with Superpowers

A semaphore is a synchronization primitive with:

  • An integer counter
  • Two atomic operations: P() (wait) and V() (signal)
  • Blocking behavior when counter is 0
Invented by: Edsger Dijkstra in 1965
P = Proberen (Dutch: "to try")
V = Verhogen ("to increment")

Binary vs. Counting Semaphores

Binary
Binary Semaphore

Initial value: 1
Acts like a mutex lock
Only 0 or 1

Counting
Counting Semaphore

Initial value: N
Allows up to N threads
Resource pool control

// Java: java.util.concurrent.Semaphore
Semaphore sem = new Semaphore(3);  // 3 permits

sem.acquire();  // P() – wait for permit
// critical section
sem.release();  // V() – return permit

P() and V() in Action

P()

Wait / Acquire
Decrement counter
If < 0 → block thread

→

Critical Section
Only if permit available

V()

Signal / Release
Increment counter
Wake one waiting thread

Classic: Producer-Consumer

Use two semaphores to solve buffer overflow/underflow.

Producer
while (true) {
    produce_item();
    empty.P();     // Wait for space
    buffer.add(item);
    full.V();      // Signal item added
}
Consumer
while (true) {
    full.P();      // Wait for item
    item = buffer.remove();
    empty.V();     // Signal space free
    consume_item();
}
Semaphores Used:
empty = N → available slots
full = 0 → items in buffer
mutex = 1 → protect buffer access

Java’s Semaphore: Real-World

// Connection pool with 10 DB connections
Semaphore pool = new Semaphore(10);

public void query() throws InterruptedException {
    pool.acquire();  // P()
    try {
        // Use DB connection
    } finally {
        pool.release();  // V()
    }
}
Fairness: new Semaphore(1, true) → FIFO order
Prevents thread starvation

Key Takeaways

1. Semaphore = counter + P/V operations.

2. Binary = mutex (0 or 1), Counting = resource pool.

3. P() = wait/decrement, V() = signal/increment.

4. Solves producer-consumer, bounded buffer.

5. Java: java.util.concurrent.Semaphore → tryAcquire, fair mode.
