5.5 PriorityBlockingQueue

Ordered Processing — High Priority First

When FIFO isn’t enough

Chapter 5 – Blocking Queues & Producer-Consumer

PriorityBlockingQueue — FIFO on Steroids

PriorityBlockingQueue is a bounded or unbounded queue where elements are ordered by priority (natural or Comparator).

Key:
• take() always returns highest priority element
• Internally: binary heap on array
• Unbounded by default (grows as needed)

High Priority Jumps the Queue

take() returns: ALERT! (10) → Report (5) → Email (3) → Backup (2)

Internal: Binary Min-Heap

Priority Task Processing

record Task(String name, int priority) implements Comparable {
    public int compareTo(Task o) {
        return Integer.compare(o.priority, priority); // Higher first
    }
}

PriorityBlockingQueue queue = new PriorityBlockingQueue<>();

// Producers add tasks
queue.put(new Task("Critical Alert", 10));
queue.put(new Task("Email", 3));
queue.put(new Task("Report", 5));

// Consumer — always gets highest priority
while (true) {
    Task task = queue.take();  // Blocks when empty
    process(task);
}

Custom Ordering

PriorityBlockingQueue queue = new PriorityBlockingQueue<>(
    100,
    Comparator.comparingInt(Task::priority).reversed()
        .thenComparing(Task::name)
);

Characteristics

Feature Value
Bounded? No (unbounded, grows)
Ordering Priority (natural or Comparator)
Fairness No
Nulls Not allowed
Performance O(log n) for put/take
Use when:
• Tasks have priorities
• Critical tasks must run first
• You can tolerate unbounded growth

Real-World Examples

// 1. Alert system
queue.put(new Alert("Server down!", 100));
queue.put(new Alert("Low disk", 50));

// 2. Job scheduler
queue.put(new Job("Backup", 1));
queue.put(new Job("Critical update", 10));

// 3. Game AI
queue.put(new Event("Player attacked", 100));
queue.put(new Event("Regenerate mana", 10));

Key Takeaways

1. PriorityBlockingQueue = ordered by priority

2. Internally: binary heap → O(log n)

3. Unbounded — grows forever

4. Elements must be Comparable or provide Comparator

5. take() returns highest priority

6. Perfect for alerts, jobs, AI events
